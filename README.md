# MAIA website

The website for MAIA, art advisory. Plain HTML and CSS, hosted on GitHub Pages.

- `index.html`: the single page
- `styles.css`: brand colours, fonts and layout, taken from the MAIA Brand Guidelines deck
- `favicon.svg`: the hair ring mark for the browser tab

Fonts: Playfair Display and Inter, loaded from Google Fonts.
Colours: Noir `#0A0A0A`, Pearl `#EDEDED`, Champagne `#C9B27C`.
